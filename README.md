# LandingPage-Pers

Este repositório contém o código-fonte de uma **Landing page**, site responsivo e otimizado para SEO.

## ✨ Funcionalidades
- Design responsivo e otimizado para dispositivos móveis.
- SEO estruturado com **meta tags** e **Schema.org**.
- Integração com **Google Analytics** para monitoramento de acessos.
- Carregamento dinâmico de produtos via **JSON** e **JavaScript assíncrono**.

## 🛠 Tecnologias Utilizadas
- **HTML5, CSS3 e JavaScript**
- **Google Analytics**
- **Schema.org** para marcação estruturada

## 🛢 Como Rodar o Projeto
1. Clone este repositório:
   ```sh
   git clone https://github.com/seuusuario/landingPage-pers.git
   ```
2. Navegue até a pasta do projeto:
   ```sh
   cd landingPage-pers
   ```
3. Abra o arquivo `index.html` no navegador.
